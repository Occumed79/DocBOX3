# Workspace dashboard template basis

The `/vault` workspace dashboard is adapted from the structural patterns of the MIT-licensed TailAdmin Free Next.js Admin Dashboard (`TailAdmin/free-nextjs-admin-dashboard`).

TailAdmin patterns used as the dashboard baseline include:

- persistent application sidebar
- compact page header and primary action
- metric cards
- dense dashboard cards instead of a marketing hero
- responsive multi-column content sections
- neutral admin-dashboard surfaces and spacing

The Occu-Med-specific workspace launcher, visualization catalog, report-template catalog, and analyst workflow content are implemented in DocBOX3.
