# Data Studio Feature Set

- Upload `.xlsx`, `.csv`, and `.tsv`
- Multi-sheet workbook selection
- Select which source row becomes the header row
- Rename columns inline
- Reorder columns
- Hide/show columns
- Delete columns
- Override inferred column types
- Edit cell values in the preview grid
- Export the cleaned dataset as CSV
- Build bar, line, area, scatter, donut, ranking, KPI, and table visualizations
- Choose aggregation method and optional series grouping where supported
- Save multiple visualizations from one dataset
- Assemble selected visualizations into a report
- Edit report title, subtitle, executive summary, and visual order
- Print or save the report as PDF
- Save the project configuration as JSON
